# NIKE DEMO - Customer Support & Product Recommendation Chatbot 👟

An interactive, responsive customer support and product discovery chatbot web application inspired by Nike. Built with modern vanilla HTML5, CSS3, and JavaScript.

## 🚀 Live Demo
You can view and test the live application directly in your browser:
👉 **[Live Demo on GitHub Pages](https://kunaldalalphs37-web.github.io/Nike-Chatbot/)**

---

## ✨ Features

- 💬 **AI-Powered Customer Support Assistant**:
  - Keyword matching and recommendation engine for footwear, clothing, and accessories.
  - Price and budget detection (e.g. *"running shoes under ₹5000"*).
  - Handles customer support queries (shipping, returns, exchange, payment methods).
  - Mock order tracking (e.g. type *"ND12345"*).
  - Quick action suggestion chips.

- 🛍️ **Interactive Product Catalog**:
  - Dynamic product search by name, sport, color, or keyword.
  - Category filters (Running, Basketball, Training, Lifestyle, Football, Clothing, Accessories).
  - Real-time price range slider up to ₹10,000.
  - Star rating filters.
  - Product detail modal with specs, sizing, and colors.
  - "Ask Chatbot About This Product" deep integration.

- 🎨 **Modern Design & UX**:
  - Dark / Light mode toggle with persistent local storage.
  - Fully responsive design for mobile, tablet, and desktop.
  - Clean Nike-inspired minimalist typography and design language.
  - Smooth animations, typing indicator, and toast notifications.

- 📬 **Support Request Form**:
  - Contact form with client-side form validation.

## 🛠️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/kunaldalalphs37-web/Nike-Chatbot.git
   ```
2. Navigate into the folder:
   ```bash
   cd Nike-Chatbot
   ```
3. Open `index.html` in any web browser, or serve it using Live Server:
   - Double-click `index.html`, OR
   - Run `npx serve .` or `python -m http.server 8000`
